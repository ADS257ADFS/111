光盒 Windows 轻量版

启动方式
--------
双击“启动光盒.exe”。软件会在自带窗口中启动，不会打开浏览器或显示服务端口。
窗口默认以屏幕 70% 大小居中显示；右上角方框按钮可在最大化与窗口化之间切换，
还原时会回到最近一次移动或调整后的窗口位置和大小。关闭光盒窗口后，内部本地服务会自动停止。

“启动光盒.bat”是兼容入口，行为与 EXE 相同。

数据位置
--------
默认用户数据目录：
%LOCALAPPDATA%\Lightbox-Windows-Clean\UserData

可以在光盒的存储位置设置中修改。

说明
--------
本目录是独立 Windows 版本，自带 Python 3.12，并使用 Windows WebView2 显示软件界面。
深色模式使用黑色标题栏，浅色模式使用白色标题栏。
