# components/ui

This folder holds UI ports for the 光盒 WebView2 shell.

The app is **not** a React / shadcn / Tailwind project. Message bubble fills from the
shadcn `MessageContent` pattern (`bg-primary` / `bg-secondary`) are applied in
`css/minimax-visual.css` on existing `.bubble.user` / `.bubble.assistant` nodes.

See `message.css` for the token mapping.
