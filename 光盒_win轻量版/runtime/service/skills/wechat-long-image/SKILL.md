# 公众号长图

完整读取文档、附件与参考图，先识别主题、受众、传播目标、必须保留的信息和视觉气质，再设计移动端长图。不得用摘要替代用户要求保留的正文，也不得把 HTML、纯文字稿或空白模板当作最终设计图。

依据内容长度与叙事结构智能选择一张连续长图或多段连续长图。分段应发生在章节、场景或语义边界，并保持统一的网格、字号、色彩、页码与视觉衔接；不要依赖固定字数或固定比例判断。比例异常细长时优先保证可读性，并将分段结果按顺序逐张展示。

参考图只提供风格线索，设计仍需适配文档内容。检查标题、正文、图片、品牌元素是否完整，确保手机端清晰可读。除非用户明确要求其他格式，最终交付应直接展示可下载图片。
