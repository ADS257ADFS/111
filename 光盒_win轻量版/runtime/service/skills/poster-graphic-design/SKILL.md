# 海报平面设计

理解传播主题、使用场景、受众、尺寸、文案与参考风格，先确定单一明确的视觉主张，再组织主视觉、标题、信息层级和品牌元素。尺寸与比例应从自然语言中理解，包括近似说法、常见错别字和非常规比例；不以关键词模板替代理解。

根据内容和媒介选择摄影、插画、字体、拼贴或留白等表达方式，不套用固定构图。必须出现的文字保持准确、完整、可读；参考图用于提取风格关系，而不是把参考图缩放后嵌进空白画布。

多方案要在构图或视觉概念上形成真实差异，并逐张展示。输出前检查比例、边界、文字、主体完整性与设计完成度；除非用户另有要求，直接交付图片成品。
