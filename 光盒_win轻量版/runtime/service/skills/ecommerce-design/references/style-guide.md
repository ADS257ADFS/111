# 电商视觉风格指南

从配色、光线、材质、构图、字体层级和装饰密度描述风格。不要直接要求模仿特定在世设计师、品牌或单张作品。

## 简约

- 配色：1–2 个主色，低饱和或中性色
- 光线：柔和、均匀、干净
- 构图：大留白、单一视觉焦点、规则网格
- 字体：简洁无衬线
- 适用：数码、护肤、家居、品质型商品

## 高端奢华

- 配色：黑、深灰、藏蓝，配少量金属色
- 光线：轮廓光、局部高光、深色渐变
- 构图：克制、对称或稳定三角构图
- 材质：金属、玻璃、丝绒、石材感
- 适用：珠宝、名酒、高端美妆和礼赠

## 国潮

- 配色：朱红、黛色、米白、金色
- 元素：抽象云纹、山水层次、印章式几何
- 构图：中轴、卷轴层次或现代中式网格
- 注意：避免堆砌符号；不要未经许可使用文物、角色或品牌纹样
- 适用：礼盒、节庆、国风服饰和传统品牌

## 科技

- 配色：蓝黑、银灰、冷色渐变
- 光线：边缘光、体积光、受控霓虹
- 元素：数据线、网格、透明界面和几何结构
- 构图：透视纵深或参数化秩序
- 适用：数码、智能家电、运动科技

## 清新自然

- 配色：浅绿、米白、天空蓝和自然原料色
- 光线：明亮、通透、柔和日光
- 元素：植物、水、原料和轻手绘纹理
- 构图：呼吸感、轻盈、不拥挤
- 适用：食品、植物护肤、母婴、清洁和家居

## 促销

- 配色：红、橙、黄等高饱和暖色
- 元素：价格牌、几何标签、动势线和彩带
- 构图：标题优先、强对比、信息分区
- 注意：价格、折扣、时限、赠品与库存必须来自用户资料
- 适用：大促、低价引流和限时活动

## 选择方法

不要只按平台选风格。按以下顺序判断：

1. 品牌已有规范
2. 商品价格带与目标人群
3. 品类常见视觉语言
4. 具体投放位的信息密度
5. 平台用户环境

用户上传参考图时，先描述其中可复用的抽象特征，再把这些特征与当前品牌约束合并。

普通海报、KV、摄影和杂志图可以作为跨类型调性参考。只提取配色、光线、材质、字体气质、背景氛围和装饰密度；不要把其横竖比例、标题位置、信息密度或整体版式直接套到商品主图或手机详情页。
