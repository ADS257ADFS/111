# 电商排版组件系统

把排版当作可组合的内容骨架，不把某张参考图当作固定整页模板。排版只决定信息结构、图片槽位、阅读顺序、留白和容量；配色、光线、材质、字体气质和装饰语言由调性参考决定。

## 参考角色

- `layout`：允许影响模块顺序、构图、槽位、占比和信息密度。
- `mood`：只允许影响配色、光线、材质、字体气质、背景氛围和装饰密度。
- 用户说“照这个风格”时默认按 `mood` 处理。
- 用户说“按这个排版”时按 `layout` 处理。
- 只有用户明确要求同时参考排版与调性，或参考图与当前物料同类型且结构适用时，才可同时采用两个角色。

## 详情页16个核心模块

| ID | 模块 | 舒适容量 | 常用变体 | 超量处理 |
|---|---|---:|---|---|
| `hero-visual` | 首屏主视觉 | 1个核心价值 | 居中、左右分栏、满版场景 | 核心价值只保留1个，其余移到后续模块 |
| `pain-point` | 用户痛点/需求场景 | 1–3个问题 | 单场景、三问题、问题与结果对照 | 超过3个时按主题分组拆屏 |
| `product-overview` | 商品整体展示 | 1个SKU或1套组合 | 单品、套装、包装展开 | 多SKU按组合关系拆分 |
| `single-benefit` | 单卖点大图 | 1个卖点 | 商品大图、细节大图、场景大图 | 不叠加第二个主卖点 |
| `dual-benefit` | 双卖点对照 | 2个卖点 | 左右、上下、前后对照 | 超过2个时切换卡片或拆屏 |
| `three-benefit-cards` | 三卡片卖点 | 2–3个短卖点 | 三列、纵向三卡、中心辐射 | 4个切四宫格；5个切1+4或拆屏 |
| `four-benefit-grid` | 四宫格卖点 | 4个短卖点 | 2×2、环绕商品、上下两组 | 文字较长时拆成2+2两屏 |
| `one-plus-four-benefits` | 核心卖点+四个次要卖点 | 1主+4次 | 上1下4、中心1周围4 | 主次不清时改为自动分组 |
| `benefit-auto-group` | 多卖点自动分组 | 5个以上 | 3+2、3+3、按主题分组 | 每屏保持一个主题，允许继续增加模块 |
| `alternating-image-text` | 图文交错 | 2–4组 | 左右交替、上下交替、大图+局部 | 超过4组时在语义边界拆屏 |
| `usage-scene` | 使用场景展示 | 1–3个场景 | 单场景大图、双场景、三场景卡片 | 超过3个时按人群或时段拆分 |
| `detail-closeup` | 商品细节特写 | 2–4个细节 | 拼贴、放大镜、局部标注 | 超过4个时按结构区域拆分 |
| `structure-principle` | 结构/原理说明 | 1个原理+3个标注 | 爆炸图、剖面、流程箭头 | 多原理分别成屏；没有事实资料时禁用 |
| `usage-steps` | 使用步骤/流程 | 3–6步 | 横向步骤、纵向时间线、场景步骤 | 超过6步时按阶段拆分 |
| `specification-comparison` | 参数/规格/对比信息 | 4–10行 | 表格、图标参数、尺寸标注 | 表格过长时分组；对比结论必须有依据 |
| `brand-service-close` | 品牌/服务/收尾 | 1个品牌主张+3–5项服务 | 品牌故事、服务卡、购买须知 | FAQ或服务过多时前置独立模块 |

## 自动组合

1. 盘点全部已证实内容，标记 `必需`、`重要`、`可选`。
2. 按语义把内容分成价值、痛点、卖点、场景、细节、原理、步骤、参数和品牌服务。
3. 每个模块只保留一个主要沟通目标。
4. 先选模块类型，再根据内容数量选择变体；不要先套固定屏数。
5. 内容超过模块容量时，按以下顺序处理：
   - 合并重复内容；
   - 按主次切换为 `1+N`；
   - 按主题、场景或步骤拆屏；
   - 增加同类模块并更换变体。
6. 避免连续三屏使用完全相同的构图；在大图、卡片、图文和信息模块之间建立节奏。
7. 内容可以扩展到10屏以上，但不得为了凑屏数虚构卖点或重复正文。

## 长详情页生成

- 先输出完整模块脚本和采用的模块ID，再逐模块生成。
- 一次只生成一个可验收模块；固定宽度、页边距、标题层级、商品版本和调性令牌。
- 只在语义边界拆屏，不把同一句话或同一组步骤截断。
- 模块之间保留可连续拼接的背景、光线或装饰过渡。
- 全部模块验收后再无损拼接，不一次生成整张超长图。

## 商品主图排版

商品主图继续按投放位选择 `白底商品图`、`营销主图`、`场景主图` 或 `直通车/广告图`。主图排版参考必须服从平台画布、商品占比、安全区和文字限制；跨类型海报只能作为调性参考。
