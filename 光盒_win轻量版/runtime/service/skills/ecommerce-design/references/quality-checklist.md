# 电商视觉验收清单

## P0：必须通过

- [ ] 商品型号、结构、颜色、包装、Logo、数量和配件与原图一致
- [ ] 没有融化、重影、错误透视、穿插、畸形边缘和多余部件
- [ ] 所有数字、参数、材质、功效、认证、价格和服务承诺均有来源
- [ ] 品牌名、规格、单位、价格、日期和标点逐字正确
- [ ] 实际像素、比例、色彩模式和格式符合具体投放位
- [ ] 平台禁止的文字、边框、水印、道具或营销元素未出现
- [ ] 不含未授权 Logo、角色、人物肖像或可识别的受保护素材

## P1：发布质量

- [ ] 3 秒内能识别商品和第一信息
- [ ] 商品与文字在移动端仍清晰
- [ ] 主标题、副标题、卖点和规则层级明确
- [ ] 文案未遮挡商品重要结构
- [ ] 四周和可能裁切区域有安全边距
- [ ] 背景、道具和光线服务于商品，不喧宾夺主
- [ ] 详情页模块的网格、色彩、商品比例和字体层级一致

## 白底图附加项

- [ ] 背景白值符合投放要求
- [ ] 商品占比符合平台/类目要求
- [ ] 阴影、倒影和道具符合投放位规则
- [ ] 无附加营销文案、徽章和水印

## 详情页附加项

- [ ] 每个模块只有一个明确任务
- [ ] 模块内容没有超过舒适容量；超量内容已切换变体或按语义拆屏
- [ ] 模块顺序形成“价值—证据—场景—参数—保障”的阅读路径
- [ ] 没有用想象数据填充空白模块
- [ ] 长页面已拆分成适合上传和修改的模块图片

## 参考图附加项

- [ ] 只采用抽象视觉特征
- [ ] 排版参考只控制模块、槽位、比例和阅读顺序
- [ ] 调性参考只控制配色、光线、材质、字体气质和装饰语言
- [ ] 跨类型海报没有直接控制主图或详情页的排版结构
- [ ] 没有复制参考图的品牌、文案、独特图形或整体布局
- [ ] 参考图来源和授权状态已记录
- [ ] 商业交付未使用 `restricted` 资源

## 交付记录

保留：

- 输入商品图和品牌资产
- 采用的参考图路径
- 已证实卖点及来源
- 生成/编辑概要
- 实际输出规格
- 待平台后台复核项
