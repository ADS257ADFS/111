# 光盒 · 软件 UI 统一视觉标准

> 本文档是光盒软件的唯一视觉规范。  
> 以后所有页面、弹窗、按钮、菜单，都必须遵守这份标准。  
> **你不需要记技术细节，看中文说明即可。**

---

## 零、视觉样板（定稿参考）

正式改代码前，先看静态样板确认感受：

| 项目 | 说明 |
|------|------|
| 位置 | `docs/prototypes/`（在软件外面，不进安装包） |
| 推荐打开 | 双击 `打开视觉样板.bat` → `spectrum-full-shell.html` |
| 当前定稿 | **v10**（深色画布网格、磨砂浮层、底部生成栏、框选工具栏） |
| 辅助说明 | `字体说明.html` — 字号、字重、描边对照 |

样板里亮/暗可切换。**两种主题只有颜色不同**，结构、字号、圆角、间距完全相同。

---

## 一、最重要的总原则

### 1. 两套主题，结构完全一样

光盒有 **两种主题**：

| 主题 | 说明 |
|------|------|
| **亮色主题** | 浅色背景，适合白天 |
| **深色主题** | 深色背景，适合夜间 |

**规则：两种主题之间，只有颜色不同。**

以下内容在亮/暗主题下 **必须完全相同**：

- 字号大小
- 字体粗细
- 圆角大小
- 间距大小
- 按钮高度
- 图标大小
- 磨砂透明度与模糊强度
- 布局位置
- 组件种类

**不允许**深色主题单独改圆角、改字号、改按钮高度。

### 2. 颜色只在「规则文件」里定义一次

所有颜色写在 `runtime/service/static/css/design-tokens.css` 这一个文件里。  
切换主题时，只换这一层的颜色值，其他地方不写 `theme-dark` 颜色分支。

### 3. 相同功能 = 相同样式

同一种按钮、同一种输入框、同一种菜单，在全软件只能有一种外观。  
不允许每个页面自己发明新颜色、新圆角、新按钮样式。

### 4. 只改视觉，不改功能

执行本标准时，只统一外观，不改变按钮功能、页面逻辑、数据流程。

### 5. 悬浮层统一用「磨砂浮层」

所有浮在画布或面板之上的菜单、工具条、胶囊面板，**同一套磨砂参数**（见第八章）。  
不允许有的用实色底、有的用模糊、有的带重投影。

## 二、颜色标准

### 说明

下表每一行是一种「用途」。  
左边是亮色主题的颜色，右边是深色主题的颜色。  
**用途名称相同，只是颜色值不同。**

### 2.1 背景色

| 用途 | 亮色主题 | 深色主题 | 用在哪里 |
|------|----------|----------|----------|
| 画布底色 | `#fcfcfc` 近白 | `#101010` 近黑 | 无限画布空白区域（实色，无条纹） |
| 窗口栏 / 侧栏 / 面板底 | `#f7f7f8` 浅灰 | `#1b1b1b` 深灰 | 左侧栏、右侧面板、设置页 |
| 顶部栏 / 主导航底 | `#fafafb` 浅灰白 | `#181818` 深灰 | 顶部标题栏、左侧一级菜单区 |
| 卡片 / 弹窗内容底 | `#ffffff` 纯白 | `#212121` 深灰 | 卡片、对话框内部 |
| **磨砂浮层底** | 白色 **80%** 透明 | 深灰 **80%** 透明 | 见第八章全部悬浮层 |
| 输入框底 | `#ffffff` 纯白 | `#1e1e1e` 深灰 | 所有输入框内部 |
| 底部输入卡片实色参考 | `#ffffff` 纯白 | `#181818` 深灰 | 生成栏底层（上覆磨砂） |

### 2.2 文字色

| 用途 | 亮色主题 | 深色主题 | 用在哪里 |
|------|----------|----------|----------|
| 主文字 | `#41444a` 炭灰 | `#d1d3d6` 浅灰 | 标题、正文、输入内容 |
| 次文字 | `#697077` 中灰 | `#9c9c9c` 中灰 | 按钮标签、字段名 |
| 辅助文字 | `#9299a2` 浅灰 | `#6e6e6e` 暗灰 | 时间、提示、占位说明 |
| 不能点击的文字 | 辅助色 46% 透明 | 辅助色 46% 透明 | 禁用状态 |
| 强调底上的白字 | `#ffffff` 白 | `#ffffff` 白 | 蓝色主按钮上的文字 |

### 2.3 强调色与状态色

| 用途 | 亮色主题 | 深色主题 | 说明 |
|------|----------|----------|------|
| 主色（强调色） | `#0a84ff` 蓝 | `#0a84ff` 蓝 | **亮暗相同** |
| 主色 Hover（鼠标放上去） | `#339dff` 亮蓝 | `#339dff` 亮蓝 | **亮暗相同** |
| 成功 | `#3dd68c` 绿 | `#3dd68c` 绿 | **亮暗相同** |
| 成功文字 | `#15803d` 深绿 | `#15803d` 深绿 | **亮暗相同** |
| 警告文字 | `#b45309` 橙 | `#b45309` 橙 | **亮暗相同** |
| 错误 / 危险 | `#ff453a` 红 | `#ff5c5c` 红 | 删除、报错 |
| 强调底白字 | `#ffffff` | `#ffffff` | 主按钮文字 |

### 2.4 边框与分割线

| 用途 | 亮色主题 | 深色主题 |
|------|----------|----------|
| 普通边框 | 黑色 10% 透明 | 白色 8% 透明 |
| 强调边框 | 黑色 16% 透明 | 白色 14% 透明 |
| 窗口分割线 | 黑色 7% 透明 | 白色 8% 透明 |
| 焦点边框 | 主色蓝 | 主色蓝 |
| 错误边框 | 错误红 | 错误红 |

### 2.5 交互态（鼠标 / 键盘操作时的底色）

| 状态 | 亮色主题 | 深色主题 | 说明 |
|------|----------|----------|------|
| Hover（鼠标放上去） | `#f3f3f4` 浅灰 | 白色 7% 透明 | 按钮、菜单项、chip 背景 |
| Pressed（鼠标按下） | 黑色 11% 透明 | 白色 15% 透明 | 按下瞬间 |
| Selected（当前选中） | 主色 10% 透明 | 主色 16% 透明 | 已选菜单项、标签、chip |
| Focus Ring（键盘焦点环） | 主色 30% 透明 | 主色 38% 透明 | 键盘 Tab 选中时 |
| 危险 Hover | 错误色 10% 透明 | 错误色 14% 透明 | 删除按钮放上去 |
| 弹窗遮罩 | 黑色 40% 透明 | 黑色 55% 透明 | 弹窗后面的半透明层 |
| 禁用透明度 | 45% | 45% | 不能点击时整体变淡 |

### 2.6 颜色使用禁令

**禁止新增以下写法：**

- 在页面 CSS 里直接写 `#0a84ff`、`#f3f3f3` 等颜色值
- 亮色和深色各写一套不同的圆角/字号/间距
- 同一种功能用不同蓝色（如 `#2563eb`、`#007aff` 等杂色蓝）
- 每个浮层自己定义不同的磨砂透明度或模糊值

**允许的唯一写法：** 使用规则名，例如 `var(--ui-accent)`、`var(--ui-hover)`、`var(--ui-glass-bg)`。

## 三、文字标准

> 亮/暗主题字号、粗细、行高 **完全相同**，只有颜色走上一节的颜色表。  
> **v10 定稿：工具栏、菜单、对话正文统一 16px。**

### 3.1 字号（全软件 4 级 + 占位）

| 等级 | 大小 | 用在哪里 |
|------|------|----------|
| 展示标题 | **18px** | 弹窗主标题、少数大标题 |
| **正文 / 控件** | **16px** | 导航、菜单、按钮、输入、对话、生成栏、框选工具栏 |
| 紧凑标签 | **14px** | 项目名、资产文件夹、搜索框、小标题 |
| 次要信息 | **13px** | 快捷键、积分、缩放比例、时间 |
| 占位说明 | **16px**（字重更细，见下） | 输入框里灰色的提示文字 |

**禁止新增：** 10px、11px、12px、12.5px、15px、20px 等其他字号（历史遗留将逐步清除）。

### 3.2 字重（粗细）

| 用途 | 字重 | 说明 |
|------|------|------|
| 普通正文 / 控件 | **380** | 菜单、按钮、chip、工具栏 |
| 英文和数字 | **350** | 自动按字符切换，**不加粗** |
| 右侧对话正文 | **300** | 仅对话区 AI/用户消息（可选） |
| 占位说明 | **250** | 仅输入框灰色提示 |
| 标题强调 | **380** | 与正文相同，**不靠加粗区分** |

**禁止：** 使用 600、700、bold 等粗体字（历史遗留将逐步清除）。

### 3.3 行高

| 用途 | 行高 |
|------|------|
| 单行按钮 / 菜单 | 1（即 100%） |
| 标题 / 卡片名 | 1.2 |
| 多行正文 / 说明 / 生成提示词 | 1.5 ~ 1.65 |

### 3.4 文字颜色对应

| 文字等级 | 用什么颜色 |
|----------|------------|
| 大标题、正文、输入内容 | 主文字色 |
| 按钮标签、字段名 | 次文字色 |
| 时间、提示、占位 | 辅助文字色 |
| 禁用 | 不能点击的文字色 |
| 主按钮上的字 | 强调底白字 |
| 成功 / 警告 / 错误提示 | 对应状态色 |

### 3.5 文字交互规则

| 规则 | 说明 |
|------|------|
| Hover 不改文字颜色 | 鼠标放上去只改背景，文字颜色不变 |
| Hover 不改字重 | 鼠标放上去文字不能变粗/变细 |
| 选中态 | 可以用主色蓝显示文字（如当前选中的菜单项、chip） |
| 危险操作 | 删除、退出等用错误红色文字 |

## 四、按钮标准

> 全软件最终只保留 **5 种基础按钮**。亮/暗主题结构相同，只有颜色不同。  
> 生成栏、框选工具栏内的 **胶囊形按钮** 属于图标/文字按钮变体，仍遵守 Hover 底色规则。

### 4.1 五种按钮

| 类型 | 类名 | 外观 | 用在哪里 |
|------|------|------|----------|
| 主要按钮 | `.ui-btn.is-primary` | 蓝底白字 | 确认、保存、发送 |
| 次要按钮 | `.ui-btn` | 透明底，有边框或无边框 | 取消、返回 |
| 描边按钮 | `.ui-btn.is-outline` | 透明底 + 边框 | 次要确认 |
| 危险按钮 | `.ui-btn.is-danger` | 红字，Hover 红底淡色 | 删除、退出账号 |
| 图标按钮 | `.ui-icon-btn` | 正方形，只有图标 | 关闭、更多、工具栏 |

### 4.2 按钮尺寸（亮暗相同）

| 尺寸 | 高度 | 用在哪里 |
|------|------|----------|
| 小 | **24px** | 标题栏内、紧凑工具条 |
| 中（默认） | **28px** | 大部分按钮 |
| 大 | **32px** | 菜单行、重要操作行 |
| 生成栏工具 | **30px ~ 36px** | 底部生成栏胶囊按钮（见第十章） |

### 4.3 按钮状态（每种按钮都必须有）

| 状态 | 视觉效果 | 亮暗差异 |
|------|----------|----------|
| 正常 | 见上表各类型默认样式 | 只有颜色不同 |
| Hover（鼠标放上去） | 背景变为 Hover 底色 | 只有颜色不同 |
| Pressed（鼠标按下） | 背景变为 Pressed 底色 | 只有颜色不同 |
| Selected（当前选中） | 选中底色 + 主色文字/边框 | 只有颜色不同 |
| Focus（键盘选中） | 主色焦点环（2px 外圈） | 只有颜色不同 |
| Disabled（不能点击） | 文字变灰，不可点击 | 只有颜色不同 |
| Loading（加载中） | 显示转圈图标，不能再次点击 | 结构相同 |

### 4.4 按钮禁止事项

- 禁止新建 `.asset-mini-btn`、`.composer-tool-btn` 等第 6 种按钮样式
- 禁止普通面板按钮带重阴影（平面风格）
- 禁止 Hover 时改变文字颜色（主要按钮白字除外）
- 禁止每个页面写不同高度的按钮

## 五、输入类标准

> 适用于：输入框、多行输入、下拉选择、复选框、开关、滑条。  
> 亮暗主题尺寸相同，只有颜色和底色不同。

### 5.1 输入框（`.ui-input`）

| 属性 | 值 |
|------|-----|
| 高度 | 28px（单行） |
| 圆角 | 6px |
| 边框 | 1px 普通边框色 |
| 内边距 | 左右 8px |
| 字号 | **16px**（与正文统一） |
| 底色 | 输入框背景色（见颜色表） |

| 状态 | 效果 |
|------|------|
| 正常 | 普通边框 |
| Hover | 边框加深 |
| Focus（点击输入） | 主色边框 + 焦点环 |
| 报错 | 错误色边框 + 淡红底环 |
| Disabled | 文字变灰，不能输入 |
| 占位文字 | 辅助文字色，字重 250 |

### 5.2 下拉选择（`.ui-select`）

与输入框相同尺寸和状态规则。右侧有下拉箭头图标。

### 5.3 复选框（`.ui-check`）

| 属性 | 值 |
|------|-----|
| 方框大小 | 15×15px |
| 圆角 | 4px |
| 选中 | 主色蓝底 + 白色勾 |

### 5.4 开关（`.ui-switch`）

| 属性 | 值 |
|------|-----|
| 轨道大小 | 32×18px |
| 圆点大小 | 14px |
| 关闭 | 灰色轨道 |
| 打开 | 主色蓝轨道，圆点移到右侧 |

### 5.5 滑条（`.ui-slider`）

| 属性 | 值 |
|------|-----|
| 轨道高度 | 3px |
| 滑块大小 | 12px 圆形 |
| 滑块颜色 | 主色蓝 |

## 六、卡片标准

| 属性 | 值 | 亮暗差异 |
|------|-----|----------|
| 背景 | 卡片背景色 | 只有颜色不同 |
| 边框 | 1px 普通边框色（可选） | 只有颜色不同 |
| 圆角 | **8px ~ 10px** | 相同 |
| 阴影 | 无（平面风格） | 相同 |
| 内边距 | 16px（默认） | 相同 |

**嵌在壳层里的卡片**（侧栏、设置页）保持平面、无阴影。

**浮在画布上的卡片**（生成栏、菜单、框选工具栏）走第八章磨砂浮层规则。

## 七、弹窗标准

### 7.1 结构

```
遮罩层（半透明黑底 + 可选模糊）
  └── 弹窗盒子
        ├── 标题栏（标题 + 关闭按钮）
        ├── 内容区
        └── 底部按钮区（可选）
```

### 7.2 尺寸等级

| 等级 | 宽度 | 用在哪里 |
|------|------|----------|
| 小 | 最小 320px | 确认框、简单提示 |
| 中（默认） | 最大 560px | 大部分弹窗 |
| 大 | 最大 1180px | 设置中心 |
| 全屏遮罩 | 居中，留边 48px | 历史记录、图片编辑 |

### 7.3 样式（亮暗结构相同）

| 属性 | 值 |
|------|-----|
| 圆角 | **14px**（大弹窗）/ **10px**（小弹窗） |
| 背景 | 卡片背景色或磨砂浮层（与第八章一致） |
| 边框 | 1px 普通边框色 |
| 遮罩 | 弹窗遮罩色 + 模糊 8px |
| 标题字号 | **18px** |
| 内容字号 | **16px** |
| 标题与内容间距 | 16px |
| 内容区内边距 | 16px |
| 底部按钮间距 | 8px |

### 7.4 弹窗按钮排列

- 主操作放右侧（主要按钮）
- 取消放左侧（次要按钮）
- 危险操作（删除）用最左侧红色按钮

## 八、磨砂浮层标准（★ v10 核心）

> 类名目标：`.ui-float`（样板中为 `.lb-float`）。  
> **全部悬浮层同一套参数**，只允许改内边距、宽度、是否胶囊形，**不允许**改透明度或模糊值。

### 8.1 统一参数（亮暗结构相同）

| 属性 | 值 | 说明 |
|------|-----|------|
| 背景透明度 | **80%** | 亮色：白 80%；深色：深灰 80% |
| 背景模糊 | **`blur(80px)`** | 必须能模糊背后画布/节点 |
| 饱和度 | `saturate(160%)` | 让背后颜色略微鲜艳 |
| 外边框 | 1px 普通边框色 | |
| 圆角 | **16px** | 胶囊形面板用 **pill（999px）** |
| 外投影 | 轻投影 | 亮色 `0 4px 18px` 黑 12%；深色 `0 4px 16px` 黑 30% |

### 8.2 必须用磨砂浮层的界面

以下 **全部** 使用同一套磨砂参数：

| 类型 | 示例 |
|------|------|
| 下拉菜单 | 用户菜单、对话标题下拉、技能包菜单 |
| 上拉菜单 | API 选择、尺寸选择、类型选择 |
| 右键菜单 | 画布右键 |
| 画布菜单 | 双击画布创建菜单 |
| 缩放菜单 | 画布右上角缩放下拉 |
| 图片工具栏 | 媒体节点上方工具条 |
| 框选工具栏 | 打组 / 整理 / 下载胶囊条（见第十一章） |
| 底部生成栏 | 主卡片 + 上方窄工具栏（见第十章） |
| 小地图 | 画布右下角 |

### 8.3 菜单容器附加规则

| 属性 | 值 |
|------|-----|
| 容器内边距 | **6px** |
| 菜单项高度 | **32px ~ 36px** |
| 菜单项圆角 | **6px ~ 8px** |
| 菜单项字号 | **16px** |
| 菜单项左右内边距 | **8px ~ 12px** |
| 图标大小 | **16px** |
| 分割线 | 1px 普通边框色，上下留 4px |

| 状态 | 效果 |
|------|------|
| Hover | Hover 底色 |
| Pressed | Pressed 底色 |
| Selected | 选中底色 + 主色文字 |
| 危险项 | 错误红色文字 |
| Disabled | 灰色文字，不能点击 |

### 8.4 Chip（选项胶囊）规则

用于 API、尺寸、比例等上拉菜单内的选项：

| 属性 | 值 |
|------|-----|
| 形态 | **button**（可点击，不是纯文字） |
| 高度 | **30px** |

### 8.5 磨砂层禁止事项

- 禁止悬浮层用纯色实底代替磨砂（菜单、生成栏除外可叠实色参考色）
- 禁止有的菜单 blur(50px)、有的 blur(80px)
- 禁止侧栏、顶栏、对话栏主体加交界处投影（`box-shadow: none`）
- 下拉菜单必须放在能模糊到背后内容的 DOM 层级（不要被 `overflow: hidden` 裁切）

## 十四、阴影标准

> 光盒整体是**平面风格**，壳层（侧栏、顶栏、对话栏）**无交界处投影**。

| 等级 | 用法 | 亮暗差异 |

## 十八、主题切换规则

### 怎么切换

- 用户菜单 → 主题切换开关
- 顶部标题栏 → 太阳/月亮按钮
- 默认：白天 6:00–18:00 亮色，其余时间深色

### 技术上怎么实现

1. 切换时只给 `<html>` 加/去 `.theme-dark` 类名
2. `design-tokens.css` 自动换颜色
3. **页面代码里不写**「如果是深色就用某某颜色」

### 窗框颜色同步

窗口外框颜色（标题栏背景）在两处保持一致：

- CSS：`desktop-window-frame.css`
- 程序：`win_launcher.py`

改颜色时必须两处一起改。窗框颜色跟随主题：亮色 `#f7f7f8`，深色 `#1b1b1b`。

## 二十、长期禁止清单

以后新增页面和功能时，**绝对不允许：**

1. 自己写新的颜色值
2. 自己写新的字号
3. 自己写新的圆角（超出第十二章层级）
4. 自己写新的阴影（壳层加投影）
5. 自己写新的按钮样式
6. 悬浮层不用统一磨砂参数
7. 亮色和深色用不同的圆角/字号/间距
8. 忽略鼠标放上去（Hover）状态
9. 忽略按下（Pressed）状态
10. 忽略选中（Selected）状态
11. 忽略不能点击（Disabled）状态
12. 忽略加载中、空数据、报错状态
13. 在组件代码里写 `theme-dark` 颜色分支
14. 画布加条纹、彩色图案底

如果现有标准真的不够用，**必须先说明原因**，批准后才能新增规则。

## 二十一、执行优先级

你确认本标准后，修改顺序为：

1. 在 `design-tokens.css` 登记磨砂浮层 token（`--ui-glass-*`）
2. 统一画布网格 token（18px / 0.6px / 深色 5.5% 白点）
3. 推广磨砂浮层组件（`.ui-float`）到全部菜单与生成栏
4. 统一正文字号为 16px
5. 删除多余覆盖层（`dark-desaturated/`、`minimax-visual.css` 里的重复规则）
6. 推广 5 种标准按钮 + chip 交互
7. 逐页替换旧样式
8. 全面查漏
