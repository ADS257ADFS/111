# 光盒 · 软件 UI 统一视觉标准

> 本文档是光盒软件的唯一视觉规范。  
> 以后所有页面、弹窗、按钮、菜单，都必须遵守这份标准。  
> **你不需要记技术细节，看中文说明即可。**

---

## 一、最重要的总原则

### 1. 两套主题，结构完全一样

光盒有 **两种主题**：

| 主题 | 说明 |
|------|------|
| **亮色主题** | 浅色背景，适合白天 |
| **深色主题** | 深色背景，适合夜间 |

**规则：两种主题之间，只有颜色不同。**

以下内容在亮/暗主题下 **必须完全相同**：

- 字号大小
- 字体粗细
- 圆角大小
- 间距大小
- 按钮高度
- 图标大小
- 阴影形状（只有颜色深浅会随主题微调）
- 布局位置
- 组件种类

**不允许**深色主题单独改圆角、改字号、改按钮高度。

### 2. 颜色只在「规则文件」里定义一次

所有颜色写在 `runtime/service/static/css/design-tokens.css` 这一个文件里。  
切换主题时，只换这一层的颜色值，其他地方不写 `theme-dark` 颜色分支。

### 3. 相同功能 = 相同样式

同一种按钮、同一种输入框、同一种菜单，在全软件只能有一种外观。  
不允许每个页面自己发明新颜色、新圆角、新按钮样式。

### 4. 只改视觉，不改功能

执行本标准时，只统一外观，不改变按钮功能、页面逻辑、数据流程。

## 二、颜色标准

### 说明

下表每一行是一种「用途」。  
左边是亮色主题的颜色，右边是深色主题的颜色。  
**用途名称相同，只是颜色值不同。**

### 2.1 背景色

| 用途 | 亮色主题 | 深色主题 | 用在哪里 |
|------|----------|----------|----------|
| 画布底色 | `#fcfcfc` 近白 | `#101010` 近黑 | 无限画布空白区域 |
| 窗口栏 / 侧栏 / 面板底 | `#f7f7f8` 浅灰 | `#1b1b1b` 深灰 | 左侧栏、右侧面板、设置页 |
| 顶部栏 / 主导航底 | `#fafafb` 浅灰白 | `#181818` 深灰 | 顶部标题栏、左侧一级菜单区 |
| 卡片 / 弹窗内容底 | `#ffffff` 纯白 | `#212121` 深灰 | 卡片、对话框内部 |
| 菜单 / 下拉浮层底 | `#ffffff` 纯白 | `#232323` 深灰 | 右键菜单、下拉菜单 |
| 输入框底 | `#ffffff` 纯白 | `#1e1e1e` 深灰 | 所有输入框内部 |
| 底部输入卡片底 | `#ffffff` 纯白 | `#181818` 深灰 | 画布底部生成输入区 |

### 2.2 文字色

| 用途 | 亮色主题 | 深色主题 | 用在哪里 |
|------|----------|----------|----------|
| 主文字 | `#41444a` 炭灰 | `#d1d3d6` 浅灰 | 标题、正文、输入内容 |
| 次文字 | `#697077` 中灰 | `#9c9c9c` 中灰 | 按钮标签、字段名 |
| 辅助文字 | `#9299a2` 浅灰 | `#6e6e6e` 暗灰 | 时间、提示、占位说明 |
| 不能点击的文字 | 辅助色 46% 透明 | 辅助色 46% 透明 | 禁用状态 |
| 强调底上的白字 | `#ffffff` 白 | `#ffffff` 白 | 蓝色主按钮上的文字 |

### 2.3 强调色与状态色

| 用途 | 亮色主题 | 深色主题 | 说明 |
|------|----------|----------|------|
| 主色（强调色） | `#0a84ff` 蓝 | `#0a84ff` 蓝 | **亮暗相同** |
| 主色 Hover（鼠标放上去） | `#339dff` 亮蓝 | `#339dff` 亮蓝 | **亮暗相同** |
| 成功 | `#3dd68c` 绿 | `#3dd68c` 绿 | **亮暗相同** |
| 成功文字 | `#15803d` 深绿 | `#15803d` 深绿 | **亮暗相同** |
| 警告文字 | `#b45309` 橙 | `#b45309` 橙 | **亮暗相同** |
| 错误 / 危险 | `#ff453a` 红 | `#ff5c5c` 红 | 删除、报错 |
| 强调底白字 | `#ffffff` | `#ffffff` | 主按钮文字 |

### 2.4 边框与分割线

| 用途 | 亮色主题 | 深色主题 |
|------|----------|----------|
| 普通边框 | 黑色 10% 透明 | 白色 8% 透明 |
| 强调边框 | 黑色 16% 透明 | 白色 14% 透明 |
| 窗口分割线 | 黑色 7% 透明 | 白色 8% 透明 |
| 焦点边框 | 主色蓝 | 主色蓝 |
| 错误边框 | 错误红 | 错误红 |

### 2.5 交互态（鼠标 / 键盘操作时的底色）

| 状态 | 亮色主题 | 深色主题 | 说明 |
|------|----------|----------|------|
| Hover（鼠标放上去） | `#f3f3f4` 浅灰 | 白色 7% 透明 | 按钮、菜单项背景 |
| Pressed（鼠标按下） | 黑色 11% 透明 | 白色 15% 透明 | 按下瞬间 |
| Selected（当前选中） | 主色 10% 透明 | 主色 16% 透明 | 已选菜单项、标签 |
| Focus Ring（键盘焦点环） | 主色 30% 透明 | 主色 38% 透明 | 键盘 Tab 选中时 |
| 危险 Hover | 错误色 10% 透明 | 错误色 14% 透明 | 删除按钮放上去 |
| 弹窗遮罩 | 黑色 40% 透明 | 黑色 55% 透明 | 弹窗后面的半透明层 |
| 禁用透明度 | 45% | 45% | 不能点击时整体变淡 |

### 2.6 颜色使用禁令

**禁止新增以下写法：**

- 在页面 CSS 里直接写 `#0a84ff`、`#f3f3f3` 等颜色值
- 亮色和深色各写一套不同的圆角/字号/间距
- 同一种功能用不同蓝色（如 `#2563eb`、`#007aff` 等杂色蓝）
- 每个弹窗自己定义背景色

**允许的唯一写法：** 使用规则名，例如 `var(--ui-accent)`、`var(--ui-hover)`。

## 三、文字标准

> 亮/暗主题字号、粗细、行高 **完全相同**，只有颜色走上一节的颜色表。

### 3.1 字号（全软件只保留 5 级）

| 等级 | 大小 | 用在哪里 |
|------|------|----------|
| 大标题 | **16px** | 页面标题、设置页大标题 |
| 正文 / 控件 | **14px** | 菜单、按钮、输入框、对话正文、面板标题 |
| 紧凑标签 | **12.5px** | 左侧项目名、画布底栏、工具栏文字 |
| 辅助信息 | **11px** | 时间、状态、标签、快捷键提示 |
| 占位说明 | **14px**（字重更细，见下） | 输入框里灰色的提示文字 |

**禁止新增：** 10px、12px、13px、15px、18px、20px 等其他字号。

### 3.2 字重（粗细）

| 用途 | 字重 | 说明 |
|------|------|------|
| 普通正文 | 380 | 大部分文字 |
| 英文和数字 | 350 | 自动按字符切换 |
| 右侧对话正文 | 300 | 仅对话区 AI/用户消息 |
| 占位说明 | 250 | 仅输入框灰色提示 |
| 标题强调 | 380 | 与正文相同，**不靠加粗区分** |

**禁止：** 使用 600、700、bold 等粗体字（历史遗留将逐步清除）。

### 3.3 行高

| 用途 | 行高 |
|------|------|
| 单行按钮 / 菜单 | 1（即 100%） |
| 标题 / 卡片名 | 1.2 |
| 多行正文 / 说明 | 1.5 |

### 3.4 文字颜色对应

| 文字等级 | 用什么颜色 |
|----------|------------|
| 大标题、正文、输入内容 | 主文字色 |
| 按钮标签、字段名 | 次文字色 |
| 时间、提示、占位 | 辅助文字色 |
| 禁用 | 不能点击的文字色 |
| 主按钮上的字 | 强调底白字 |
| 成功 / 警告 / 错误提示 | 对应状态色 |

### 3.5 文字交互规则

| 规则 | 说明 |
|------|------|
| Hover 不改文字颜色 | 鼠标放上去只改背景，文字颜色不变 |
| Hover 不改字重 | 鼠标放上去文字不能变粗/变细 |
| 选中态 | 可以用主色蓝显示文字（如当前选中的菜单项） |
| 危险操作 | 删除、退出等用错误红色文字 |

## 四、按钮标准

> 全软件最终只保留 **5 种按钮**。亮/暗主题结构相同，只有颜色不同。

### 4.1 五种按钮

| 类型 | 类名 | 外观 | 用在哪里 |
|------|------|------|----------|
| 主要按钮 | `.ui-btn.is-primary` | 蓝底白字 | 确认、保存、发送 |
| 次要按钮 | `.ui-btn` | 透明底，有边框或无边框 | 取消、返回 |
| 描边按钮 | `.ui-btn.is-outline` | 透明底 + 边框 | 次要确认 |
| 危险按钮 | `.ui-btn.is-danger` | 红字，Hover 红底淡色 | 删除、退出账号 |
| 图标按钮 | `.ui-icon-btn` | 正方形，只有图标 | 关闭、更多、工具栏 |

### 4.2 按钮尺寸（亮暗相同）

| 尺寸 | 高度 | 用在哪里 |
|------|------|----------|
| 小 | **24px** | 标题栏内、紧凑工具条 |
| 中（默认） | **28px** | 大部分按钮 |
| 大 | **32px** | 菜单行、重要操作行 |

### 4.3 按钮状态（每种按钮都必须有）

| 状态 | 视觉效果 | 亮暗差异 |
|------|----------|----------|
| 正常 | 见上表各类型默认样式 | 只有颜色不同 |
| Hover（鼠标放上去） | 背景变为 Hover 底色 | 只有颜色不同 |
| Pressed（鼠标按下） | 背景变为 Pressed 底色 | 只有颜色不同 |
| Selected（当前选中） | 选中底色 + 主色文字/边框 | 只有颜色不同 |
| Focus（键盘选中） | 主色焦点环（2px 外圈） | 只有颜色不同 |
| Disabled（不能点击） | 文字变灰，不可点击 | 只有颜色不同 |
| Loading（加载中） | 显示转圈图标，不能再次点击 | 结构相同 |

### 4.4 按钮禁止事项

- 禁止新建 `.asset-mini-btn`、`.composer-tool-btn` 等第 6 种按钮样式
- 禁止按钮带阴影（平面风格）
- 禁止 Hover 时改变文字颜色（主要按钮除外，白字保持白字）
- 禁止每个页面写不同高度的按钮

## 五、输入类标准

> 适用于：输入框、多行输入、下拉选择、复选框、开关、滑条。  
> 亮暗主题尺寸相同，只有颜色和底色不同。

### 5.1 输入框（`.ui-input`）

| 属性 | 值 |
|------|-----|
| 高度 | 28px（单行） |
| 圆角 | 6px |
| 边框 | 1px 普通边框色 |
| 内边距 | 左右 8px |
| 字号 | 14px |
| 底色 | 输入框背景色（见颜色表） |

| 状态 | 效果 |
|------|------|
| 正常 | 普通边框 |
| Hover | 边框加深 |
| Focus（点击输入） | 主色边框 + 焦点环 |
| 报错 | 错误色边框 + 淡红底环 |
| Disabled | 文字变灰，不能输入 |
| 占位文字 | 辅助文字色，字重 250 |

### 5.2 下拉选择（`.ui-select`）

与输入框相同尺寸和状态规则。右侧有下拉箭头图标。

### 5.3 复选框（`.ui-check`）

| 属性 | 值 |
|------|-----|
| 方框大小 | 15×15px |
| 圆角 | 4px |
| 选中 | 主色蓝底 + 白色勾 |

### 5.4 开关（`.ui-switch`）

| 属性 | 值 |
|------|-----|
| 轨道大小 | 32×18px |
| 圆点大小 | 14px |
| 关闭 | 灰色轨道 |
| 打开 | 主色蓝轨道，圆点移到右侧 |

### 5.5 滑条（`.ui-slider`）

| 属性 | 值 |
|------|-----|
| 轨道高度 | 3px |
| 滑块大小 | 12px 圆形 |
| 滑块颜色 | 主色蓝 |

## 六、卡片标准

| 属性 | 值 | 亮暗差异 |
|------|-----|----------|
| 背景 | 卡片背景色 | 只有颜色不同 |
| 边框 | 1px 普通边框色（可选） | 只有颜色不同 |
| 圆角 | **8px** | 相同 |
| 阴影 | 无（平面风格） | 相同 |
| 内边距 | 16px（默认） | 相同 |

**带浮起感的卡片**（如底部输入白面、工具栏、用户菜单）可使用 `--ui-shadow-float` 浮层阴影，亮暗阴影颜色不同但形状相同。

## 七、弹窗标准

### 7.1 结构

```
遮罩层（半透明黑底）
  └── 弹窗盒子
        ├── 标题栏（标题 + 关闭按钮）
        ├── 内容区
        └── 底部按钮区（可选）
```

### 7.2 尺寸等级

| 等级 | 宽度 | 用在哪里 |
|------|------|----------|
| 小 | 最小 320px | 确认框、简单提示 |
| 中（默认） | 最大 560px | 大部分弹窗 |
| 大 | 最大 1180px | 设置中心 |
| 全屏遮罩 | 居中，留边 48px | 历史记录、图片编辑 |

### 7.3 样式（亮暗结构相同）

| 属性 | 值 |
|------|-----|
| 圆角 | 10px |
| 背景 | 卡片背景色 |
| 边框 | 1px 普通边框色 |
| 遮罩 | 弹窗遮罩色 + 模糊 8px |
| 标题字号 | 14px |
| 内容字号 | 14px |
| 标题与内容间距 | 16px |
| 内容区内边距 | 16px |
| 底部按钮间距 | 8px |

### 7.4 弹窗按钮排列

- 主操作放右侧（主要按钮）
- 取消放左侧（次要按钮）
- 危险操作（删除）用最左侧红色按钮

## 十、圆角标准

> **亮暗完全相同。全软件只保留 3 种圆角 + 2 种特殊。**

| 名称 | 大小 | 用在哪里 |
|------|------|----------|
| 控件圆角 | **6px** | 按钮、输入框、菜单项 |
| 卡片圆角 | **8px** | 卡片、菜单容器、下拉面板 |
| 面板圆角 | **10px** | 弹窗、大面板、底部输入卡片 |
| 圆形 | **50%** | 头像、圆点、滑条滑块 |
| 长条圆角 | **6px** | 标签、胶囊形控件（不再用大圆角胶囊） |

**禁止：** 12px、14px、16px、18px、22px 等大圆角（历史遗留将逐步清除）。

## 十一、间距标准

> **亮暗完全相同。全软件只保留 8 级间距。**

| 名称 | 大小 | 常见用途 |
|------|------|----------|
| 极小 | 2px | 图标与文字微调 |
| 很小 | 4px | 紧凑内边距 |
| 小 | 6px | 按钮内图标间距 |
| 标准 | 8px | 菜单项内边距、小间隙 |
| 中间 | 12px | 表单项之间、卡片内组间距 |
| 大 | 16px | 卡片内边距、区块间距 |
| 很大 | 20px | 面板内边距 |
| 超大 | 24px | 页面级间距 |
| 特大 | 32px | 大区块分隔 |

**禁止：** 10px、15px、18px、22px 等非标准间距。

---

## 十二、阴影标准

> 光盒整体是**平面风格**，大部分组件无阴影。

| 等级 | 用法 | 亮暗差异 |
|------|------|----------|
| 无阴影 | 按钮、面板、卡片、工具栏 | 相同（都没有） |
| 浮层阴影 | 底部输入白面、工具栏、右键菜单、用户菜单 | 阴影颜色深浅不同，形状相同 |
| 窗口阴影 | 由 Windows 程序绘制，不在网页里写 | 程序控制 |

**禁止：** 给普通按钮、侧栏、面板加阴影。

## 十四、画布专用标准

> 画布区域有少量专用颜色，同样遵循亮暗只有颜色不同的原则。

| 用途 | 说明 |
|------|------|
| 网格点 | 亮色：淡黑点；深色：淡白点 |
| 选中框 | 主色蓝 |
| 选中填充 | 主色 8%（亮）/ 12%（暗）透明 |
| 节点边框 | 1px 普通边框色 |
| 节点选中边框 | 1.5px 主色蓝 |
| 对齐辅助线 | 主色蓝 |

## 十六、主题切换规则

### 怎么切换

- 用户菜单 → 主题切换开关
- 顶部标题栏 → 太阳/月亮按钮
- 默认：白天 6:00–18:00 亮色，其余时间深色

### 技术上怎么实现

1. 切换时只给 `<html>` 加/去 `.theme-dark` 类名
2. `design-tokens.css` 自动换颜色
3. **页面代码里不写**「如果是深色就用某某颜色」

### 窗框颜色同步

窗口外框颜色（标题栏背景）在两处保持一致：

- CSS：`desktop-window-frame.css`
- 程序：`win_launcher.py`

改颜色时必须两处一起改。窗框颜色跟随主题：亮色 `#f7f7f8`，深色 `#1b1b1b`。

## 十七、唯一规则源（改一处，全软件跟着变）

| 想改什么 | 只改这个文件 |
|----------|-------------|
| 颜色（含亮/暗） | `design-tokens.css` |
| 按钮 / 输入框 / 菜单组件 | `ui-primitives.css` |
| 窗框颜色（程序层） | `win_launcher.py` |

**禁止**在业务页面 CSS 里直接写颜色值、字号、圆角。  
**必须**使用规则名，例如 `var(--ui-accent)`、`var(--ui-space-4)`。

## 十八、长期禁止清单

以后新增页面和功能时，**绝对不允许：**

1. 自己写新的颜色值
2. 自己写新的字号
3. 自己写新的圆角
4. 自己写新的阴影
5. 自己写新的按钮样式
6. 亮色和深色用不同的圆角/字号/间距
7. 忽略鼠标放上去（Hover）状态
8. 忽略按下（Pressed）状态
9. 忽略选中（Selected）状态
10. 忽略不能点击（Disabled）状态
11. 忽略加载中、空数据、报错状态
12. 在组件代码里写 `theme-dark` 颜色分支

如果现有标准真的不够用，**必须先说明原因**，批准后才能新增规则。

---

## 十九、执行优先级（第三阶段预告）

你确认本标准后，修改顺序为：

1. 统一颜色规则文件（亮/暗颜色）
2. 删除多余覆盖层（`dark-desaturated/`、`minimax-visual.css` 里的重复规则）
3. 推广 5 种标准按钮
4. 推广标准输入框 / 菜单 / 弹窗
5. 逐页替换旧样式
6. 全面查漏
