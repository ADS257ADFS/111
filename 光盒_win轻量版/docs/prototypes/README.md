# 光盒视觉样板说明

> 参考：Adobe Spectrum 2 桌面端（medium 尺度）+ Express 友好圆润浮层  
> 结构参考：Figma / Canva 类 PC 画布创作工具  
> **本阶段只改样板文件，不修改正式产品代码。**

## 如何查看

在光盒软件启动后，用浏览器或 WebView 打开：

| 样板 | 地址 | 内容 |
|------|------|------|
| **A · 创作工作区壳层** | `/static/prototypes/spectrum-workspace-shell.html` | 顶栏 + 左侧栏 + 画布 + 底栏 + 右侧面板 |
| **B · 浮层与交互组件** | `/static/prototypes/spectrum-floating-ui.html` | 按钮、输入、菜单、弹窗、特殊状态 |

右上角可切换 **亮色 / 深色** 主题。

## 我替你定的参数（你不用记数字）

### 圆角分层（核心策略）

| 区域 | 圆角 | 原因 |
|------|------|------|
| 侧栏行、列表项 | **6px** | 结构区克制，保信息密度 |
| 按钮、输入框 | **8px** | 统一交互控件圆润感 |
| 卡片、底栏 | **10px** | 轻微圆润，不抢画布 |
| 菜单、工具栏、提示 | **12px** | Express 友好浮层 |
| 弹窗 | **14px** | 明显层级，不过大 |
| 画布区域 | **0px** | 干净克制 |

### 控件高度

| 尺寸 | 高度 | 用途 |
|------|------|------|
| 小 | 24px | 顶栏、紧凑工具 |
| 中 | 30px | 默认按钮、输入、导航 |
| 大 | 32px | 菜单行 |

### 字号

| 等级 | 大小 |
|------|------|
| 标题 | 14px |
| 正文 | 13px |
| 紧凑 | 12px |
| 辅助 | 11px |

### 颜色

- 灰阶结构对齐 Spectrum gray-25～900
- 主色保留光盒蓝 `#0a84ff`
- 亮/暗 **只有颜色不同**，尺寸圆角间距完全相同

### 阴影

- 画布、侧栏、面板：**无阴影**
- 浮层（菜单、底栏、弹窗）：**轻阴影**

## 请你反馈的方式

看样板后，直接告诉我感受即可，例如：

- 太圆了 / 不够圆
- 按钮太大 / 太小
- 侧栏太挤 / 太空
- 亮色太亮 / 深色太暗
- 整体太重 / 太轻

我会根据你的反馈自动调整参数，确认后再固化为全项目唯一标准。
