# 光盒视觉样板说明

> **这些文件在软件外面，不属于光盒安装包。**  
> 参考：Adobe Spectrum 2 桌面端 + Express 圆润浮层  
> **不修改正式产品代码。**

## 怎么打开（推荐）

### 方式 1：双击 bat 文件（最简单）

1. 打开文件夹：`光盒_win轻量版/docs/prototypes/`
2. 双击 **`打开视觉样板.bat`**
3. 会直接打开 **完整壳层样板**，包含软件里所有主要面板

### 方式 2：双击 HTML

| 文件 | 说明 |
|------|------|
| `spectrum-full-shell.html` | **★ 完整壳层（推荐）** — 真实布局，所有面板同时展示 |
| `字体说明.html` | 字号、字重、各区域字体对照 |
| `index.html` | 入口页，列出全部样板 |
| `spectrum-workspace-shell.html` | 简化版工作区（旧） |
| `spectrum-floating-ui.html` | 浮层组件集（旧） |

### 方式 3：右键用浏览器打开

如果双击后没反应：右键 HTML → 打开方式 → **Chrome** 或 **Edge**

---

## 完整壳层包含的面板

- 顶栏（搜索、主题、窗口控制、积分）
- 左侧导航 + 最近创作 + **用户面板**
- 画布 **网格点** + 节点 + **连线**
- **双击画布菜单** + **右键菜单**
- 画布右上工具 + **缩放下拉菜单**
- 媒体上方 **图片工具栏**
- 底部 **生成栏** + API/类型/尺寸 **上拉菜单**
- 右侧 **对话栏** + 标题 **下拉菜单** + 技能包菜单 + 发送按钮
- 小地图

页面内可切换 **亮色 / 深色** 主题（左下角按钮）。
