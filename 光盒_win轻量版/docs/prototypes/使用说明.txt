  光盒视觉样板 · 怎么打开（请按顺序做）
═══════════════════════════════════════

【第一步】找到这个文件夹

  在你的电脑里，打开：

    光盒_win轻量版 → docs → prototypes

  （就是「使用说明.txt」所在的这个文件夹）


【第二步】双击打开（推荐第一种）

  ★ 双击：打开视觉样板.bat
    → 会直接打开「完整壳层样板」

  或者双击：spectrum-full-shell.html

  字体说明：字体说明.html


【完整壳层里有什么】

  ✓ 顶栏、左侧栏、右侧对话栏
  ✓ 画布网格点、节点、连线
  ✓ 双击画布菜单、右键菜单
  ✓ 媒体上方工具栏
  ✓ 底部生成栏 + 上拉菜单
  ✓ 左下角用户面板
  ✓ 右侧对话标题下拉、技能包菜单
  ✓ 字体说明单独一页


【重要提醒】

  ✓ 用 Chrome、Edge 等浏览器看
  ✓ 整个 prototypes 文件夹要在一起

  ✗ 不要在光盒软件里打开
  ✗ 不要用网上复制的浏览器地址


【看完怎么反馈】

  直接说感受，例如：
  · 太圆了 / 不够圆
  · 按钮太大 / 太小
  · 字体太大 / 太小
  · 太亮 / 太暗

  不需要说具体数字。
