  光盒视觉样板 · 怎么打开（请按顺序做）
═══════════════════════════════════════

【第一步】找到这个文件夹

  在你的电脑里，打开：

    光盒_win轻量版 → docs → prototypes

  （就是「使用说明.txt」所在的这个文件夹）


【第二步】双击打开（推荐第一种）

  ★ 双击：打开视觉样板.bat

  或者双击：index.html

  或者双击：spectrum-workspace-shell.html（直接看样板 A）


【重要提醒】

  ✓ 用 Chrome、Edge 等浏览器看
  ✓ 整个 prototypes 文件夹要在一起，不要只复制某一个文件

  ✗ 不要在光盒软件里打开
  ✗ 不要用网上/聊天里复制的浏览器地址
  ✗ 不要只打开 GitHub 网页上的代码预览


【如果还是打不开】

  1. 右键 index.html →「打开方式」→ 选 Chrome 或 Edge

  2. 确认你有最新文件（需要更新到含样板的代码版本）

  3. 把浏览器里显示的错误文字发给我（或截图）


【看完怎么反馈】

  直接说感受即可，例如：
  · 太圆了 / 不够圆
  · 按钮太大 / 太小
  · 太挤 / 太空
  · 太亮 / 太暗

  不需要说具体数字。
