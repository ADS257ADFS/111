光盒字体说明

这份说明告诉你：软件里用什么字体、多大、用在哪里。亮/暗主题只有颜色不同，字号和字重完全相同。

正式字体名称：MiSans（小米字体）
软件里会根据中英文自动切换合适字重，你不需要自己选。

一、字体家族（用在哪里）

名称说明用在
MiSans 界面主字体，中英文混排 全部界面：按钮、菜单、侧栏、画布、对话栏
JetBrains Mono 等宽字体（每个字一样宽） 代码、技术参数（很少出现）

如果电脑没装 MiSans，会自动用 微软雅黑 UI 或 Segoe UI 代替，看起来差不多。

二、字号（多大）

大小名称用在哪里预览
16px 展示标题 页面大标题、弹窗主标题 光盒视觉样板标题
14px 正文 / 控件 按钮文字、输入框、菜单项、对话内容、侧栏导航 新建画布 · 描述你想生成的图片
12.5px 紧凑标签 最近项目名、画布底栏按钮、媒体工具栏、缩放比例 未命名画布 · 100% · 裁切
11px 次要信息 快捷键提示、时间戳、积分角标、分组小标题 Ctrl + Z · 预计消耗 5 积分

三、字重（粗细）

字重适用预览（14px）
380 中文正文、按钮、菜单（默认） 中文界面默认粗细
350 英文、数字（比中文略细一点） Lightbox 2365 100%
250 输入框占位提示（灰色说明文字） 描述你想生成或编辑的图片…

界面区域字号字重

底部生成栏按钮12px600（偏粗）
右侧对话标题12.5px380
右侧对话内容14px380
右侧对话输入框14px380（占位 250）

五、重要原则

  • 亮/暗主题：只有颜色变，字号和字重不变
  • 全软件统一：不按页面单独设计字体
  • 创作工具密度：比手机 App 更紧凑，比管理后台更透气
  • 只有 4 档字号：16 / 14 / 12.5 / 11，不再增加新尺寸
