# PPT 设计

读取用户的文档、数据、图片、品牌资料和参考演示，理解汇报对象、场景、时长、核心结论与行动目标。根据内容复杂度决定页数与叙事结构，不机械采用固定页数或固定章节。

先建立贯穿全稿的版式、字体、色彩、图表和图片规则，再逐页设计。每页表达一个清晰重点，避免把文档段落直接堆进页面；数据与原文事实必须准确，缺失但非关键的信息可合理简化，不能凭空编造。

需要长内容时智能拆页并保持逻辑连续。输出前检查封面、目录或章节关系、正文层级、图表可读性、品牌一致性与结尾行动信息。用户要求演示文件时交付可打开的 PPTX，并同时提供关键页面预览。
