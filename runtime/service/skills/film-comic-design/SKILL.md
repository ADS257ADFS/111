# 影视漫剧

从故事目标、角色关系、世界观、情绪节奏和发布媒介出发理解需求。读取剧本、人物设定、分镜文档和参考图，建立人物外观、服装、场景、光线、色彩与镜头语言的一致性，而不是逐句套模板。

根据任务自行判断应产出概念图、角色设定、场景气氛图、镜头关键帧、分镜或连续漫剧画面。缺少会破坏连续性的关键信息时再提问，其余细节可基于上下文合理推断并保持前后一致。

多镜头按叙事顺序逐张生成与展示，每张都要有明确镜头意图。输出前检查角色身份、空间关系、动作衔接、比例和画风连续性；最终优先直接交付视觉成品。
