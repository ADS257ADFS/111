# 生成与编辑提示结构

把设计概要转换成结构化指令。不要堆砌形容词；优先明确主体保真、构图、信息层级、光线、材质和禁用项。

## 通用结构

```text
任务：生成/编辑 [投放位]，[尺寸或比例]
商品主体：[商品外观与必须保真信息]
目标：[受众、场景、核心沟通目标]
排版：[模块ID、布局变体、主体位置、占比、槽位、留白区域、视觉动线]
容量：[内容项数量、舒适容量、超量时的切换或拆屏方案]
调性：[风格、配色、光线、背景、材质、字体气质、装饰密度]
文案：[只列已证实且必须出现的文字]
排版参考：[只列允许影响结构的参考图及采用的槽位特征]
调性参考：[只列配色、光线、材质、字体气质和装饰特征]
约束：[不得改变的商品细节、平台禁用元素、版权与合规限制]
输出：[数量、格式、是否需要透明背景]
```

## 指令优先级

- 用户提示词高于本文件中的系统模板。
- 用户参考图高于系统参考图库。
- 排版参考只影响结构；调性参考不直接改变模块顺序、文字密度和平台画布。
- 用户文字与用户参考图冲突时，以用户明确文字为准。
- 系统模板只补齐用户没有指定的构图、光线、层级和输出细节。
- 上述优先级不能覆盖商品真实性、平台硬性规则和合规要求。

## 基于商品图编辑

明确要求：

- 保留商品的结构、包装、Logo、颜色、比例和数量。
- 不增加不存在的按钮、接口、配件、纹理或文字。
- 只修改背景、光线、道具、版式和经确认的营销信息。
- 商品边缘清晰，无融化、重影、穿插和错误反射。

## 商品营销主图

```text
将提供的商品图制作成 [平台/投放位] 营销主图。
画布 [尺寸]。商品占画面约 [比例]，位于 [位置]。
在 [区域] 保留干净文案空间，形成 [层级]。
采用 [风格]，主色 [颜色]，光线 [描述]。
只呈现以下已证实文案：[文案]。
不得改变商品包装、Logo、颜色、数量和配件。
不得添加未经确认的价格、销量、认证或功效。
```

## 白底商品图

```text
把商品置于纯白背景，均匀专业棚拍光线，边缘清晰。
保持商品真实颜色和几何结构，不添加文字、徽章、边框、水印或未包含配件。
按投放位要求控制商品占比和阴影。
```

亚马逊主图必须同时遵守 `platform-specs.md` 的硬性约束。

## 详情页模块

读取 `layout-system.md`，先输出完整模块脚本，再逐模块生成：

```text
模块编号：
模块目标：
排版模块ID：
布局变体：
内容项数量与容量判断：
超量处理/拆屏关系：
已证实卖点：
主标题：
辅助说明：
商品/场景画面：
证据或细节：
调性令牌：
画布：
```

逐模块生成，并在所有模块中固定：

- 商品版本和包装
- 主色与辅助色
- 标题层级和网格
- 光线方向与材质语言
- 页边距和模块间节奏

当卖点数量与模板容量不一致时，不压缩字号硬塞：

- 1个卖点使用 `single-benefit`
- 2个卖点使用 `dual-benefit`
- 3个卖点使用 `three-benefit-cards`
- 4个卖点使用 `four-benefit-grid`
- 5个卖点根据主次使用 `one-plus-four-benefits`，或拆成3+2
- 6个以上使用 `benefit-auto-group`，按主题增加模块

## 精确文字

图像生成模型可能出现错字。处理顺序：

1. 生成带明确留白和版式占位的视觉底图。
2. 使用确定性排版工具叠加最终文案。
3. 逐字核对品牌名、数字、单位、价格、日期和标点。
4. 无法排版时交付无字底图、最终文案和位置标注，不声称文字已完成。
