# 卖点真实性与文案指南

## 证据分级

在制作文案前，为每条信息标注等级：

| 等级 | 定义 | 是否可直接作为事实 |
|---|---|---|
| 已证实 | 来自用户参数表、包装、检测报告、品牌官网、授权资料或可靠官方来源 | 可以 |
| 待确认 | 来自文件名、模糊截图、竞品页面、外观推测或无法追溯的资料 | 不可以 |
| 创意表达 | 不包含可验证事实的情绪、场景或审美表达 | 可以，但不能暗示未证实功效 |

## 绝对禁止

- 不把“质量很好”改造成具体材质、等级或工艺。
- 不把“很保湿”改造成“72 小时保湿”。
- 不把“杀菌效果好”改造成“99% 杀菌”。
- 不从商品外观推断容量、续航、成分、原产地、认证或适用人群。
- 不把竞品信息写成当前商品的事实。
- 不伪造或弱化改写销量、评价、热销、人气、爆款、排名、专家推荐、专利、检测机构或认证标志。

## 敏感品类

以下内容必须有明确证据，并提醒用户自行完成投放前合规审查：

- 食品与保健品：疾病预防、治疗、减重、降血糖、无添加、有机等。
- 美妆护肤：美白、祛斑、防脱、生发、医学推荐、敏感肌适用等。
- 母婴：年龄适用、安全等级、无毒、抗菌和过敏相关主张。
- 医疗器械与健康产品：治疗效果、准确率、临床数据和适应症。
- 数码家电：续航、功率、防水等级、能效、快充协议和认证。

## 提炼顺序

1. 汇总用户提供的商品事实。
2. 找出目标人群最关心的问题。
3. 将事实转换成“特征 → 用户利益 → 使用场景”。
4. 为每条文案保留证据来源。
5. 按投放位压缩字数。

示例：

```text
已证实特征：容量 2000 ml
用户利益：减少频繁添水
场景表达：办公室一天饮水更省心
主图短句：2000ml 大容量
```

## 字数建议

| 投放位 | 数量 | 单条长度 |
|---|---:|---:|
| 商品营销主图 | 1–2 条 | 4–10 个汉字 |
| 详情页首屏 | 1 条主标题 + 1 条副标题 | 主标题 6–16 字 |

这是可读性建议，不是平台规则。

## 中性改写

无法核实具体数字时，保留原意但去掉虚构量化：

| 不安全写法 | 安全改写 |
|---|---|
| 72 小时长效保湿 | 删除时长，只保留已证实的保湿用途 |
| 99% 高效杀菌 | 删除比例和杀菌主张，只保留已证实的清洁用途 |
| 全网销量第一 | 删除排名措辞，改写为有证据的产品利益 |
| 医生推荐 | 删除推荐措辞，改写为有证据的产品特征 |
| 绝对防水 | 标记防护能力待确认，不直接使用 |

若中性表达仍可能构成功效或性能主张，标为待确认，不直接使用。

## 竞品研究

竞品只能用于了解表达方向和信息结构：

1. 明确平台、站点、品类和时间范围。
2. 记录来源与访问日期。
3. 统计常见诉求，不复制竞品文案。
4. 只用当前商品资料中能够证实的差异。
5. 没有浏览或可靠数据时，不声称分析了 TOP 商品。
